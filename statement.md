## Problem Statement

Keeping track of daily expenses can be difficult when expenses are recorded separately. This project provides a simple Python-based way to add expenses and view the recorded expenses in one place.

The program allows the user to enter the date, category, description, and amount of an expense. The entered expense is stored in a list in the form of a dictionary.

The program also allows the user to view all the added expenses and calculate the total spending.

## Objectives

The main objectives of this project are:

- To add and store expenses.
- To view all recorded expenses.
- To calculate the total spending.
- To practice Python lists and dictionaries.
- To use loops, conditions, and user input in a practical program.

## Working of the Project

When the program starts, it displays a menu with four choices:

- Add Expense
- View All Expenses
- View Total Spending
- Exit

For adding an expense, the user enters the date, category, description, and amount. These details are stored in a dictionary, and the dictionary is added to the expense list.

When the user selects the option to view expenses, the program displays each stored expense.

For total spending, the program goes through all stored expenses and adds their amounts to calculate the total expense.

The program continues showing the menu until the user selects the exit option.

- `while` loop
- `for` loop
- Conditional statements

## Expected Outcome
